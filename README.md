## ✨ Características Principales

* **Tableros Visuales:** Organiza el flujo de trabajo con el sistema Kanban. Mueve tarjetas, asigna responsables y define fechas límite.
* **Colaboración Centralizada:** Mantén a todo el equipo sincronizado para operar con alto rendimiento.
* **Automatización:** Configuración de reglas personalizadas para reducir el trabajo manual en tareas repetitivas.
* **Experiencia de Usuario (UX):** Interfaz fluida con gestión de rutas de producción y vistas de error (404) personalizadas de forma nativa.

## 🛠️ Stack Tecnológico y Arquitectura

* **Backend:** Python operando sobre el framework Django.
* **Base de Datos:** Arquitectura preparada para integrarse con MySQL (utilizando `mysql.connector`).
* **Frontend:** Construcción nativa en HTML5 y CSS3 puro, manteniendo el proyecto ligero y sin dependencias externas innecesarias.
* **Entorno:** Desarrollo aislado mediante entornos virtuales (`venv`) para garantizar estabilidad.
